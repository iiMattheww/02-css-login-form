# CSS Login / Registration Form

A simple, responsive login and registration UI built with plain HTML, CSS and a small JavaScript toggle. Includes smooth transitions, social icons, and mobile-friendly styles.

**Features**
- **Responsive:** adapts layout for mobile and desktop.
- **Transitions:** animated panel toggle between Login and Register.
- **No frameworks:** built with vanilla `HTML`, `CSS`, and `JavaScript`.

**Files**
- `Index.html` — main markup
- `style.css` — styling and responsive rules
- `main.js` — toggle behavior for panels

**Usage**
- Open `Index.html` in a browser to preview the form.
- To publish, push this repository to GitHub and enable GitHub Pages (optional).
